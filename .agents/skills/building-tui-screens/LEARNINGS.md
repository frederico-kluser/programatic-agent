- [2026-08-04][source:inference][task:devgraph-tui-picker][probation] Put a screen's payload on the `Screen` VARIANT, never on `FsmState`. `{ kind: 'graph-detail'; graphId: string }` (screen-fsm.ts) carries its id in the variant precisely so the screen is self-describing: a `currentGraphId` field on `FsmState` would survive a screen change and make the next visit inspect the wrong drawing.
